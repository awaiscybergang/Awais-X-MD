## 🚀 Installation

### STEP 01 — Clone the Repository

```bash
git clone https://github.com/awaiscybergang/Awais-X-MD.git
cd Awais-X-MD
```

### STEP 02 — Install Dependencies

```bash
npm install
```

*(Use the package manager and scripts defined in the real `package.json`.)*

### STEP 03 — Configure Environment

Create a configuration file based on the project’s actual config structure (`.env`, `config.js`, `settings.json`, etc.).

**Never commit real secrets.**

Typical variables (adjust to match source):

```env
# Example placeholders — replace with actual names from the codebase
SESSION_ID=
OWNER_NUMBER=923295533214
PREFIX=.
BOT_NAME=AWAIS X MD
# AI / media API keys if required
```

### STEP 04 — Pair WhatsApp

Follow the pairing method implemented in the source (QR code or pairing code).  
A related session tool is available at:  
[Awais-Session-Generator](https://github.com/awaiscybergang/Awais-Session-Generator)

### STEP 05 — Start the Bot

```bash
npm start
```

*(Or the exact start script from `package.json`.)*

### STEP 06 — Verify

1. Confirm the bot connects successfully.
2. Send a basic command (e.g. menu / help) from an authorized number.
3. Check console logs for any missing environment variables or API errors.

## 🔧 Troubleshooting

| Issue | Possible Solution |
|-------|-------------------|
| Missing dependencies | Run `npm install` again; check Node version ≥ 18 |
| Invalid / missing API keys | Add keys only in local env / config — never commit them |
| Pairing / connection fails | Clear old session data, re-pair, ensure stable network |
| Media download errors | Verify FFmpeg, API endpoints, and rate limits |
| Unsupported Node version | Upgrade to the version required by `package.json` |
| Bot offline after restart | Check process manager (PM2, systemd) and logs |

---

## 🛡 Security

- **Never** publish API keys, session files, or `.env` contents.
- **Never** upload WhatsApp auth / session credentials to GitHub.
- Keep owner numbers and privileged commands restricted.
- Respect user privacy and WhatsApp terms of service.
- Avoid spam, unauthorized bulk messaging, or abusive automation.
- Review third-party downloaders and AI providers for their own terms.
