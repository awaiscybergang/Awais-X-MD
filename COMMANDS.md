# AWAIS X MD — All Commands (167)

Prefix: **`.`** (dot). A message is a command only if it starts with `.` — normal chat never triggers the bot.
Send `.menu` in WhatsApp for the live list. Settings commands (auto-react, anti-*, setimage) work only from the owner's own WhatsApp account.
